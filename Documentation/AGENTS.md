# Агенты и MCP

Aircraft умеет работать как браузер для ИИ-агентов. Внутри приложения есть MCP-сервер. Через него Claude Code, Claude Desktop, Cursor и другие MCP-клиенты открывают страницы, читают их, кликают, вводят текст и делают скриншоты в настоящих вкладках Aircraft.

## Включение

**Настройки → Агенты → Разрешить агентам управлять браузером.**

- Сервер слушает только `127.0.0.1` (порт по умолчанию `7777`). С других компьютеров он недоступен.
- Каждый запрос должен нести токен `Authorization: Bearer <токен>`. Кнопка «Новый токен» сразу отключает всех подключённых агентов.
- Запросы со сторонним заголовком `Origin` отклоняются. Так веб-страница не сможет обратиться к серверу из браузера.
- Пока агент работает со вкладкой, вокруг страницы видна рамка, а внизу плашка «Агент управляет вкладкой».

Агент действует в ваших вкладках с вашими входами на сайты. Включайте доступ только для агентов, которым доверяете.

## Подключение

### Через `aircraft-mcp` (stdio, рекомендуется)

`aircraft-mcp` лежит внутри приложения: `Aircraft.app/Contents/MacOS/aircraft-mcp`. Он берёт порт и токен из `~/Library/Application Support/Aircraft/agent.json`. Если Aircraft не запущен, `aircraft-mcp` запускает его сам. Новый токен и смену порта он тоже подхватывает без перенастройки.

```sh
claude mcp add aircraft -- /Applications/Aircraft.app/Contents/MacOS/aircraft-mcp
```

Claude Desktop, Cursor и другие клиенты с JSON-конфигом:

```json
{
  "mcpServers": {
    "aircraft": { "command": "/Applications/Aircraft.app/Contents/MacOS/aircraft-mcp" }
  }
}
```

Переменные `AIRCRAFT_MCP_URL` и `AIRCRAFT_MCP_TOKEN` переопределяют адрес и токен.

### Напрямую по HTTP

Транспорт — MCP Streamable HTTP. Сервер отвечает JSON, без SSE:

```sh
claude mcp add --transport http aircraft http://127.0.0.1:7777/mcp --header "Authorization: Bearer <токен>"
```

Готовые команды с подставленными путём и токеном есть в **Настройки → Агенты**.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `browser_tabs` | Окна и вкладки: id, заголовки, адреса |
| `browser_open_tab` | Новая вкладка с адресом или поисковым запросом |
| `browser_select_tab` / `browser_close_tab` | Переключить / закрыть вкладку |
| `browser_navigate` | Открыть адрес и дождаться загрузки |
| `browser_history` | Назад, вперёд, обновить |
| `browser_fullscreen` | Окно во весь экран macOS и обратно |
| `browser_snapshot` | Заголовки и видимые интерактивные элементы со ссылками `[e12]` |
| `browser_get_text` | Текст страницы постранично |
| `browser_screenshot` | JPEG видимой части; 1 пиксель = 1 CSS-пиксель |
| `browser_window_screenshot` | JPEG всего окна: панель вкладок, папки, Spotlight, просмотрщики |
| `browser_click` | Клик по `ref`, по тексту или по координатам |
| `browser_type` | Ввод текста в поле, опционально с Enter |
| `browser_press_key` | Клавиши и сочетания: `Enter`, `Shift+Tab`, `Meta+A`… |
| `browser_scroll` | Прокрутка страницы или до элемента |
| `browser_select_option` | Выбор варианта в `<select>` |
| `browser_wait_for` | Ждать текст, его исчезновение или CSS-селектор |
| `browser_evaluate` | Выполнить JavaScript на странице |
| `browser_console` | Сообщения консоли и необработанные ошибки |

Без `tabId` инструменты работают с активной вкладкой переднего окна. Если вкладка указана, она выходит на передний план. Если вкладка на экране, клики и клавиши отправляются настоящими событиями macOS, и для страницы они неотличимы от действий пользователя (`isTrusted`). Для вкладок вне экрана используется JavaScript.

Окна инкогнито агентам не видны. Включить их можно в **Настройки → Конфиденциальность**.

Для отладки Aircraft можно запустить с отдельной папкой данных: переменная окружения `AIRCRAFT_DATA_DIR` заменяет `~/Library/Application Support/aircraft`, и туда же пишется `agent.json`.

Служебные скрипты работают в изолированном мире WebKit (`WKContentWorld.defaultClient`): страница не может их подменить. `browser_evaluate` и перехват консоли работают в мире самой страницы.

## Ограничения

- Элементы внутри iframe и закрытого Shadow DOM в `browser_snapshot` не попадают. Используйте скриншот и клик по координатам.
- Загрузка файлов через `<input type=file>` и системные диалоги пока не поддерживаются.
- Консоль записывается для вкладок, открытых после включения сервера. Для остальных запись начинается с первого вызова `browser_console`.
