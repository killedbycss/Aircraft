# Aircraft Mod SDK 0.2

Модификации — это локальные файлы `.js` и `.css`, которые Aircraft внедряет в основную рамку каждой страницы. Добавить файл можно в **Настройки → Продвинутый функционал → Добавить файл**. После установки открытые страницы пересоздаются, чтобы мод начал работать сразу.

## Структура JavaScript-мода

```js
(() => {
  "use strict";

  // Всегда ограничивайте мод нужными сайтами.
  if (location.hostname !== "example.com") return;

  const MOD_ID = "example-cleanup";
  if (document.documentElement.dataset[MOD_ID]) return;
  document.documentElement.dataset[MOD_ID] = "1";

  // Код модификации.
})();
```

Мод должен быть идемпотентным: повторный запуск не создаёт дубликаты обработчиков, стилей или элементов.

## Aircraft JavaScript API

API доступен как `window.aircraft` с события `aircraft:ready`:

```js
window.addEventListener("aircraft:ready", () => {
  console.log(window.aircraft.version);
});
```

Доступные методы:

- `aircraft.closeTab()` — закрыть активную вкладку;
- `aircraft.newTab()` — создать вкладку;
- `aircraft.openTab(url)` — открыть URL или поисковый запрос в новой вкладке;
- `aircraft.reload()` — обновить активную вкладку;
- `aircraft.openSpotlight()` — открыть Spotlight с текущим URL;
- `aircraft.openSettings()` — открыть настройки;
- `aircraft.toggleReaderMode()` — переключить режим чтения;
- `aircraft.enableDevTools()` — разрешить Web Inspector для текущей вкладки;
- `aircraft.storage.get(key, fallback)` — прочитать локальное значение мода;
- `aircraft.storage.getAll()` — получить копию хранилища;
- `aircraft.storage.set(key, value)` — сохранить JSON-совместимое значение;
- `aircraft.storage.remove(key)` — удалить значение;
- `aircraft.post(action, payload)` — низкоуровневый вызов bridge.

## CSS-моды

Файл `.css` применяется глобально ко всем страницам. Для модификации конкретного домена предпочтительнее JS-файл, который проверяет `location.hostname` и добавляет собственный `<style>`.

## Динамические сайты

Для SPA используйте `MutationObserver`, но наблюдайте минимально возможный контейнер и группируйте изменения:

```js
const observer = new MutationObserver(() => requestAnimationFrame(update));
observer.observe(document.body, { childList: true, subtree: true });
```

Отключайте observer, таймеры и обработчики, когда они больше не нужны.

## Ограничения и безопасность

- Моды выполняются с правами открытой страницы. Устанавливайте только проверенный код.
- Не сохраняйте пароли, токены и персональные данные.
- Не перехватывайте формы авторизации и платёжные страницы.
- Хранилище SDK общее для всех сайтов: используйте уникальный префикс ключа и не кладите туда секреты.
- Не выполняйте постоянный polling; используйте DOM-события и `MutationObserver`.
- Не изменяйте `window.webkit.messageHandlers` напрямую — используйте `window.aircraft`.

## Чек-лист для разработчика или AI-агента

1. Назвать целевые домены и проверить `location.hostname`.
2. Сделать мод идемпотентным и добавить уникальный ID.
3. Не блокировать главный поток тяжёлыми циклами.
4. Учесть SPA-навигацию и динамический DOM.
5. Проверить светлую и тёмную темы сайта.
6. Проверить desktop и mobile режим Aircraft.
7. Описать, какие элементы и события меняет мод.
8. Отдать один самодостаточный `.js` или `.css` файл без внешних зависимостей.

## Рекомендуемая инструкция AI-агенту

> Создай самодостаточный Aircraft-мод в одном JS-файле. Ограничь его доменами [домены], добавь защиту от повторного запуска, не используй внешние зависимости, polling и доступ к секретам. Для динамического DOM используй экономный MutationObserver. Совместимость: Aircraft Mod SDK 0.2, desktop и mobile режимы. В конце кратко перечисли изменения и риски.

## Готовые модификации

- **Блокировщик рекламы** (встроенный, **Настройки → Блокировщик**): нативные правила WebKit не загружают рекламные сети и прячут рекламные блоки. Встроенный список работает без интернета; дополнительно — подписки на EasyList/AdGuard и другие списки, свои правила, пипетка «Скрыть элемент» (⌥⌘B), отдельная защита от рекламы Яндекса и Google/YouTube. На отдельных сайтах защиту можно отключить.
- **Блокировщик трекеров** (там же): не загружает счётчики, пиксели и сервисы записи сессий, а также убирает из ссылок метки `utm_*`, `fbclid`, `gclid`, `yclid` и подобные.
- **DevTools + WebExtensions**: локальная консоль, журнал `fetch` и мост `chrome.runtime`, `chrome.storage.local`, `chrome.tabs.create`. Открыть — `⌘⌥I`.
- **Цветные темы**: пять локальных цветовых режимов. Панель — кнопка `◐` или `⌃⌥T`.
- **История и аккаунты**: до 300 локальных переходов и список сайтов, где обнаружен активный вход. Открыть — `⌘Y`.
- **Разделение экрана**: добавляет команду «Разделить экран» в контекстное меню вкладки. Вторая страница загружается только после выбора команды.

Aircraft использует WebKit, поэтому `.crx` и Chrome Manifest V3 целиком не поддерживаются. Мост покрывает только перечисленное подмножество API.
