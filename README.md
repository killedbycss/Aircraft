# Aircraft 0.3 alpha

Экспериментальный браузер для macOS на SwiftUI и WebKit.

Aircraft использует ленивую загрузку вкладок, восстанавливает сессию и поддерживает отключаемые модификации через Mod SDK 0.2.

## Требования

- macOS 15 или новее
- Xcode с Swift 6

## Сборка

```sh
./Scripts/build-app.sh
```

Готовое приложение появится в `dist/Aircraft.app`.

Тесты:

```sh
swift test
```

## Структура

- `Sources/EasyBrowser` — SwiftUI-интерфейс, вкладки и WebKit;
- `Examples/Mods` — отключаемые модификации;
- `Sources/EasyBrowser/Agent` — встроенный MCP-сервер для агентов;
- `Sources/AircraftMCP` — `aircraft-mcp`, stdio-мост для MCP-клиентов;
- `Documentation/MODIFICATIONS.md` — документация Mod SDK;
- `Documentation/AGENTS.md` — подключение агентов по MCP;
- `Scripts/build-app.sh` — release-сборка `.app`;
- `Tests` — тесты URL-маршрутизации.

## Модификации

В комплект входят DevTools/WebExtensions bridge, цветные темы, локальная история/список активных входов и разделение экрана. Они не запускаются до установки в **Настройки → Продвинутый функционал**.

После установки моды встраиваются в основной интерфейс:

- выбор цветной темы появляется в разделе **Внешний вид**;
- **Инструменты**, **История и аккаунты** и **Разделить экран** добавляются в конец бокового или горизонтального меню вкладок;
- split-screen открывает пустую страницу во второй панели; размеры меняются перетаскиванием разделителя, а открытая страница выбирается в заголовке панели.

Встроенные **блокировщик рекламы** и **блокировщик трекеров** включаются в **Настройки → Модификации**. Они работают на нативных правилах WebKit, без расширений и без интернета.

Полная загрузка Chrome `.crx` не поддерживается: Aircraft использует WebKit, а не Chromium. Мост реализует документированное подмножество API.

## Агенты (MCP)

Aircraft может работать браузером для ИИ-агентов: Claude Code, Claude Desktop, Cursor и других MCP-клиентов. Доступ включается в **Настройки → Агенты**, после этого:

```sh
claude mcp add aircraft -- /Applications/Aircraft.app/Contents/MacOS/aircraft-mcp
```

Агент открывает страницы, читает их, кликает, вводит текст, делает скриншоты и выполняет JavaScript в настоящих вкладках. Подробности и список инструментов — в `Documentation/AGENTS.md`.

## Основные сочетания клавиш

- `⌘⇧` (нажать и отпустить) — открыть/закрыть Spotlight с URL текущей вкладки
- `⌘T` / `⌘N` — новая пустая вкладка с открытым Spotlight
- `⌘⇧N` — новое окно
- `⌘1`…`⌘8` — перейти на вкладку по номеру, `⌘9` — на последнюю вкладку
- `⌘W` — закрыть активную вкладку
- `⌘R` — обновить активную вкладку
- `⌘[` / `⌘]` — назад / вперёд
- `⌃⌥S` — показать или скрыть панель вкладок
- `F12` (или `fn F12`) / `⌥⌘I` — открыть/закрыть Web Inspector текущей вкладки; «Проверить элемент» есть в контекстном меню
- `⌘`-клик по ссылке — открыть её в фоновой вкладке справа от текущей

Вкладки, которые открывает страница (ссылки в новой вкладке, `window.open`), появляются справа от неё, а не в конце списка. Когда скрывать верхнюю панель вкладок — всегда, только в оконном режиме или никогда — выбирается в **Настройки → Вкладки**.

Для закреплённой вкладки `⌘W` возвращает исходный закреплённый URL; явная кнопка закрытия удаляет вкладку.

## Распространение

Исходный код удобно публиковать в GitHub-репозитории, а собранный `Aircraft-0.3-alpha.zip` прикладывать к GitHub Release с тегом `v0.3-alpha`.

Локальная сборка подписывается ad-hoc. Для распространения без предупреждений Gatekeeper потребуется сертификат Apple Developer ID, hardened runtime и notarization.
