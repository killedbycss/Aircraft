# Aircraft 0.3 alpha

Экспериментальный браузер для macOS на SwiftUI и WebKit.

Aircraft использует ленивую загрузку вкладок, восстанавливает все окна прошлой сессии и поддерживает отключаемые модификации через Mod SDK 0.2.

## Возможности

- **Оформление как в Arc** — цвет или градиент из двух цветов тонирует панель вкладок и рамку окна, страница — карточкой со скруглёнными углами (**Настройки → Основные → Цвет окна**).
- **Liquid Glass** (по желанию, **Настройки → Основные → Liquid Glass**): окно просвечивает рабочий стол, боковая и верхняя панели, Spotlight, плашки и нижняя строка — стекло macOS 26; страницы остаются непрозрачными карточками. На macOS до 26 — полупрозрачные материалы.
- **Открыть в приложении**, как в Safari и Chrome: ссылки на созвоны Zoom и Teams, Telegram, Spotify, Discord, Slack, Notion, Figma, Linear и Apple Music предлагают открыться в установленном приложении (плашка над страницей и значок приложения в карточке адреса). Если страница сама открывает приложение (`zoommtg://`, `tg://`…), Aircraft спрашивает разрешения; можно разрешить сайту навсегда.
- **Боковая панель**: стрелки «назад/вперёд» (удерживайте или правый клик — список страниц), карточка адреса с заголовком страницы, **плитки избранных сайтов** в рамке цвета значка, цветные папки. Внизу — профиль, «История и аккаунты» и **загрузки** (`⌥⌘L`). У каждого значка подсказка с сочетанием клавиш. Свайп двумя пальцами — назад и вперёд.
- **Профили** — у каждого свои cookie и входы на сайты, история, закладки, настройки сайтов и вкладки. Переключатель внизу панели вкладок, `⌃1`…`⌃9`. Вкладки неактивного профиля выгружаются из памяти.
- **Папки вкладок** с вложенностью до трёх уровней, перетаскивание мышью во всех видах панели, выделение нескольких вкладок `⌘`-кликом.
- **Группы**: ссылка, открытая в новой вкладке, собирается в группу вместе со страницей, с которой её открыли.
- **Автоархив** вкладок, которые давно не открывали (12 часов … 30 дней, **Настройки → Вкладки**).
- **Инкогнито** (`⌘⇧N`): данные только в памяти, ничего не пишется на диск.
- **История** с полнотекстовым поиском, **аккаунты** (сайты, где выполнен вход) и **закладки** с папками; импорт закрепов (из Arc — закреплённые вкладки и избранное, из Dia — закреплённые вкладки с папками, из остальных — панель закладок), закладок и истории из Safari, Chrome, Arc, Dia, Brave, Edge, Vivaldi, Opera, Яндекс Браузера, Comet, Helium, Thorium, любого другого Chromium-браузера (папка профиля) и HTML-файла (**Настройки → Браузер → Импорт**). Входы на сайты браузеры шифруют, поэтому их перенести нельзя.
- **Spotlight** в духе Arc: большое поле, до пяти подсказок с названиями страниц и значками (остальные — прокруткой): открытые вкладки, закладки, история, архив и запросы поисковика. `⌘↩` открывает результат в новой вкладке, `Tab` — URL-система.
- **Закрепы не теряются**: `⌘W` на закреплённой вкладке возвращает её к закреплённому адресу и выгружает, а при закрытии одного из окон его закрепы переходят в соседнее окно.
- **Поиск на странице**, **масштаб** для каждого сайта, **возврат закрытых вкладок** вместе с историей переходов, **звук** вкладок, **картинка в картинке**.
- **Разрешения сайтов**: камера, микрофон и геопозиция спрашиваются плашкой над страницей; решения — в **Настройки → Конфиденциальность**.
- **Режим чтения** со шрифтами, размером, шириной и темами (меню «Вид»; можно повесить на `⌘⇧R`).
- **Источники** (мод, **Настройки → Модификации**) — библиотека литературы в духе Zotero: `⌘⇧S` сохраняет открытую статью или страницу с авторами, журналом, датой, DOI, тегами, снимком страницы и PDF (метатеги Google Scholar `citation_*`, Dublin Core, Open Graph, JSON-LD; работает и за логином). Коллекции, поиск, правка карточки, ссылки по ГОСТ Р 7.0.100 и APA 7, экспорт в BibTeX, RIS и готовый список литературы.
- **Сайты видят Safari**: User-Agent с версией установленного Safari — Google не пишет «браузер устарел», входы через Google, Microsoft и SSO вузов работают. По желанию — «Chrome только для Google» или для всех (**Настройки → Браузер → Сайты**). Вход по логину и паролю (HTTP Basic/Digest/NTLM) спрашивается окном, с «Запомнить в связке ключей».
- **localhost**: `:3000`, `localhost:5173`, `127.0.0.1:8080`, `*.localhost` открываются по http; значок порта в карточке адреса, `⌘R` без кэша, вкладки разработки не усыпляются и не архивируются, сертификат локального сервера принимается, «сервер не отвечает» — подсказкой.
- **Сайт как приложение**: **Закладки → Добавить сайт в Dock** собирает отдельное приложение в папке «Программы» (`/Applications`, если нет прав — `~/Applications`) со своей иконкой и своими входами.
- **Кнопки окна** стоят по центру верхней панели вкладок или шапки боковой панели; когда боковая панель не закреплена, кнопка «Закрепить» — под ними. Ширина боковой панели — 190…420 pt.
- **Новая вкладка не дублируется**: `⌘T` переходит на уже открытую пустую вкладку, а пустая вкладка, с которой ушли, закрывается. «+» внизу панели — меню: вкладка, папка, папка в закреплённых, разделить экран, окно.
- **Плитки в полосе вкладок** (сверху) собраны в одну кнопку с меню.
- **Split View**: клик по странице переводит на неё фокус, рамка показывает активную панель, `⌥⌘←/→` — переключение, кнопки «поменять местами» и «убрать панель», двойной клик по разделителю — поровну, `⇧↩` в Spotlight открывает рядом.
- **Ссылки из других приложений** открываются обычной вкладкой, даже если сейчас открыта плитка или закреплённая вкладка.
- **Узкое окно**: внизу — стрелки, адрес и кнопка вкладок, вкладки выезжают сбоку, адрес — под рядом значков.
- **PDF** открывается во встроенном просмотрщике (миниатюры, оглавление, поиск, печать), в том числе файлы за логином.
- **Markdown** — просмотр и редактор: режимы «Просмотр / Правка / Исходник», живой предпросмотр, панель форматирования, `⌘S` — сохранить, `⌘E` — правка; оформление (тема, шрифт, размер, ширина), оглавление, подсветка кода и живое обновление при сохранении в другом редакторе.

Данные хранятся в `~/Library/Application Support/aircraft`; сессия версии 0.3 переносится автоматически.

## Требования

- macOS 15 или новее
- Xcode с Swift 6

## Сборка

```sh
./Scripts/build-app.sh
```

Готовое приложение появится в `dist/Aircraft.app`.

Тесты:

```sh
swift test
```

## Структура

- `Sources/EasyBrowser` — SwiftUI-интерфейс, вкладки и WebKit;
- `Examples/Mods` — отключаемые модификации;
- `Sources/EasyBrowser/Agent` — встроенный MCP-сервер для агентов;
- `Sources/AircraftMCP` — `aircraft-mcp`, stdio-мост для MCP-клиентов;
- `Sources/AircraftWebApp` — `aircraft-webapp`, оболочка для сайтов, добавленных в Dock;
- `Documentation/MODIFICATIONS.md` — документация Mod SDK;
- `Documentation/AGENTS.md` — подключение агентов по MCP;
- `Scripts/build-app.sh` — release-сборка `.app`;
- `Tests` — тесты маршрутизации URL, блокировщика, дерева вкладок, Markdown, закладок, истории и импорта.

## Модификации

Модами остаётся только то, что заметно нагружает систему: DevTools/WebExtensions bridge (скрипт в каждой странице) и разделение экрана (вторая живая страница). Они не запускаются до установки в **Настройки → Продвинутый функционал**. Цветные темы и «История и аккаунты» теперь встроены, их старые файлы при запуске убираются в Корзину.

После установки моды встраиваются в основной интерфейс:

- **Разделить экран** — кнопка внизу боковой панели и пункт контекстного меню вкладки; split-screen открывает пустую страницу во второй панели, размеры меняются перетаскиванием разделителя, а открытая страница выбирается в заголовке панели;
- Web Inspector открывается `F12` / `⌥⌘I`.

Встроенный блокировщик настраивается в **Настройки → Блокировщик** (⌘, — настройки открываются в отдельном окне). Он работает на нативных правилах WebKit, без расширений:

- блокировщик рекламы и трекеров со встроенными списками, работает и без интернета;
- отдельные переключатели против рекламы **Яндекса** (Директ, Карты, Маркет, РСЯ, анти-адблок) и **Google/YouTube** (поиск, AdSense, реклама в роликах);
- подписки на списки фильтров: EasyList, AdGuard (русский, Base, трекеры, cookie-баннеры, всплывающие окна), RU AdList, EasyPrivacy и любые свои по адресу. Списки обновляются автоматически;
- свои правила в синтаксисе Adblock Plus / uBlock Origin и пипетка «Скрыть элемент на странице» (⌥⌘B);
- список сайтов, где блокировка отключена.

Полная загрузка Chrome `.crx` не поддерживается: Aircraft использует WebKit, а не Chromium. Мост реализует документированное подмножество API.

## Агенты (MCP)

Aircraft может работать браузером для ИИ-агентов: Claude Code, Claude Desktop, Cursor и других MCP-клиентов. Доступ включается в **Настройки → Агенты**, после этого:

```sh
claude mcp add aircraft -- /Applications/Aircraft.app/Contents/MacOS/aircraft-mcp
```

Агент открывает страницы, читает их, кликает, вводит текст, делает скриншоты и выполняет JavaScript в настоящих вкладках. Подробности и список инструментов — в `Documentation/AGENTS.md`.

## Основные сочетания клавиш

- `⌘⇧` (нажать и отпустить) — открыть/закрыть Spotlight с URL текущей вкладки
- `⌘T` — новая пустая вкладка с открытым Spotlight
- `⌘N` — новое окно, `⌘⇧N` — окно инкогнито
- `⌘1`…`⌘8` — перейти на вкладку по номеру, `⌘9` — на последнюю вкладку
- `⌥←` / `⌥→` — предыдущая / следующая вкладка (кроме случаев, когда курсор в поле ввода или открыт Spotlight)
- `⌘W` — закрыть активную вкладку (в Split View — только активную панель; окно `⌘W` не закрывает, работает в любой раскладке), `⌘⇧T` — вернуть закрытую
- `⌘R` — обновить активную вкладку, `⌘⇧R` / `⌥⌘R` — обновить без кэша (`⌘⇧R` настраивается), `⌘.` — остановить загрузку
- `⌘[` / `⌘]` — назад / вперёд
- `⌘F`, `⌘G` / `⌘⇧G` — поиск на странице
- `⌘=` / `⌘−` / `⌘0` — масштаб (запоминается для сайта)
- `⌘⇧C` — скопировать ссылку без меток отслеживания
- `⌘⇧M` — выключить или включить звук вкладки
- `⌘⇧S` — сохранить страницу в «Источники» (мод)
- `⌥⌘←` / `⌥⌘→` — левая / правая панель Split View
- `⌘D` — добавить в закладки, `⌘⇧B` — закладки, `⌘Y` — история и аккаунты, `⌥⌘L` — загрузки
- `⌃1`…`⌃9` — профиль по номеру
- `⌘O` — открыть PDF, Markdown или HTML
- `⌃⌥S` — показать или скрыть панель вкладок
- `F12` (или `fn F12`) / `⌥⌘I` — открыть/закрыть Web Inspector текущей вкладки; «Проверить элемент» есть в контекстном меню
- свайп двумя пальцами — назад / вперёд; удерживать стрелку или правый клик по ней — список страниц
- `⌘`-клик по ссылке — открыть её в фоновой вкладке рядом с текущей (в группе)

Вкладки, которые открывает страница (ссылки в новой вкладке, `window.open`), собираются в группу вместе с ней. Это выключается в **Настройки → Вкладки**. Когда скрывать незакреплённую панель вкладок (слева, справа или сверху) — всегда, только в оконном режиме или никогда — выбирается в **Настройки → Вкладки → Скрывать панель**.

Для закреплённой вкладки и плитки `⌘W` возвращает исходный закреплённый URL, выгружает вкладку и переключается на соседнюю; явная кнопка закрытия удаляет вкладку.

`⌘⇧` открывает Spotlight, только если между нажатием и отпусканием не было других клавиш, — снимок экрана (`⌘⇧3/4/5`) его больше не вызывает.

## Распространение

Исходный код удобно публиковать в GitHub-репозитории, а собранный `Aircraft-0.3-alpha.zip` прикладывать к GitHub Release с тегом `v0.3-alpha`.

Локальная сборка подписывается ad-hoc. Для распространения без предупреждений Gatekeeper потребуется сертификат Apple Developer ID, hardened runtime и notarization.
