# Aircraft 0.4 alpha

Экспериментальный браузер для macOS на SwiftUI и WebKit.

Aircraft использует ленивую загрузку вкладок, восстанавливает все окна прошлой сессии и поддерживает отключаемые модификации через Mod SDK 0.2.

## Возможности

- **Профили** — у каждого свои cookie и входы на сайты, история, закладки, настройки сайтов и вкладки. Переключатель внизу панели вкладок, `⌃1`…`⌃9`. Вкладки неактивного профиля выгружаются из памяти.
- **Папки вкладок** с вложенностью до трёх уровней, перетаскивание мышью во всех видах панели, выделение нескольких вкладок `⌘`-кликом.
- **Группы**: ссылка, открытая в новой вкладке, собирается в группу вместе со страницей, с которой её открыли.
- **Автоархив** вкладок, которые давно не открывали (12 часов … 30 дней, **Настройки → Вкладки**).
- **Инкогнито** (`⌘⇧P`): данные только в памяти, ничего не пишется на диск.
- **История** с полнотекстовым поиском и **закладки** с папками; импорт из Safari, Chrome, Arc, Brave, Edge, Vivaldi и HTML-файла (**Настройки → Браузер → Импорт**).
- **Spotlight** подсказывает открытые вкладки, закладки, историю, архив и запросы поисковика, дописывает адреса посещённых сайтов. `⌘↩` открывает результат в новой вкладке.
- **Поиск на странице**, **масштаб** для каждого сайта, **возврат закрытых вкладок** вместе с историей переходов, **звук** вкладок, **картинка в картинке**.
- **Разрешения сайтов**: камера, микрофон и геопозиция спрашиваются плашкой над страницей; решения — в **Настройки → Конфиденциальность**.
- **Режим чтения** (`⌘⇧R`) со шрифтами, размером, шириной и темами.
- **Сайт как приложение**: **Закладки → Добавить сайт в Dock** собирает отдельное приложение со своей иконкой и своими входами.
- **PDF** открывается во встроенном просмотрщике (миниатюры, оглавление, поиск, печать), в том числе файлы за логином.
- **Markdown** — с оглавлением, подсветкой кода, режимом «Исходник» и живым обновлением локальных файлов при сохранении.

Данные хранятся в `~/Library/Application Support/aircraft`; сессия версии 0.3 переносится автоматически.

## Требования

- macOS 15 или новее
- Xcode с Swift 6

## Сборка

```sh
./Scripts/build-app.sh
```

Готовое приложение появится в `dist/Aircraft.app`.

Тесты:

```sh
swift test
```

## Структура

- `Sources/EasyBrowser` — SwiftUI-интерфейс, вкладки и WebKit;
- `Examples/Mods` — отключаемые модификации;
- `Sources/EasyBrowser/Agent` — встроенный MCP-сервер для агентов;
- `Sources/AircraftMCP` — `aircraft-mcp`, stdio-мост для MCP-клиентов;
- `Sources/AircraftWebApp` — `aircraft-webapp`, оболочка для сайтов, добавленных в Dock;
- `Documentation/MODIFICATIONS.md` — документация Mod SDK;
- `Documentation/AGENTS.md` — подключение агентов по MCP;
- `Scripts/build-app.sh` — release-сборка `.app`;
- `Tests` — тесты маршрутизации URL, блокировщика, дерева вкладок, Markdown, закладок, истории и импорта.

## Модификации

В комплект входят DevTools/WebExtensions bridge, цветные темы, локальная история/список активных входов и разделение экрана. Они не запускаются до установки в **Настройки → Продвинутый функционал**.

После установки моды встраиваются в основной интерфейс:

- выбор цветной темы появляется в разделе **Внешний вид**;
- **Инструменты**, **История и аккаунты** и **Разделить экран** добавляются в конец бокового или горизонтального меню вкладок;
- split-screen открывает пустую страницу во второй панели; размеры меняются перетаскиванием разделителя, а открытая страница выбирается в заголовке панели.

Встроенный блокировщик настраивается в **Настройки → Блокировщик** (⌘, — настройки открываются в отдельном окне). Он работает на нативных правилах WebKit, без расширений:

- блокировщик рекламы и трекеров со встроенными списками, работает и без интернета;
- отдельные переключатели против рекламы **Яндекса** (Директ, Карты, Маркет, РСЯ, анти-адблок) и **Google/YouTube** (поиск, AdSense, реклама в роликах);
- подписки на списки фильтров: EasyList, AdGuard (русский, Base, трекеры, cookie-баннеры, всплывающие окна), RU AdList, EasyPrivacy и любые свои по адресу. Списки обновляются автоматически;
- свои правила в синтаксисе Adblock Plus / uBlock Origin и пипетка «Скрыть элемент на странице» (⌥⌘B);
- список сайтов, где блокировка отключена.

Полная загрузка Chrome `.crx` не поддерживается: Aircraft использует WebKit, а не Chromium. Мост реализует документированное подмножество API.

## Агенты (MCP)

Aircraft может работать браузером для ИИ-агентов: Claude Code, Claude Desktop, Cursor и других MCP-клиентов. Доступ включается в **Настройки → Агенты**, после этого:

```sh
claude mcp add aircraft -- /Applications/Aircraft.app/Contents/MacOS/aircraft-mcp
```

Агент открывает страницы, читает их, кликает, вводит текст, делает скриншоты и выполняет JavaScript в настоящих вкладках. Подробности и список инструментов — в `Documentation/AGENTS.md`.

## Основные сочетания клавиш

- `⌘⇧` (нажать и отпустить) — открыть/закрыть Spotlight с URL текущей вкладки
- `⌘T` / `⌘N` — новая пустая вкладка с открытым Spotlight
- `⌘⇧N` — новое окно, `⌘⇧P` — окно инкогнито
- `⌘1`…`⌘8` — перейти на вкладку по номеру, `⌘9` — на последнюю вкладку
- `⌥←` / `⌥→` — предыдущая / следующая вкладка (кроме случаев, когда курсор в поле ввода)
- `⌘W` — закрыть активную вкладку, `⌘⇧T` — вернуть закрытую
- `⌘R` — обновить активную вкладку
- `⌘[` / `⌘]` — назад / вперёд
- `⌘F`, `⌘G` / `⌘⇧G` — поиск на странице
- `⌘=` / `⌘−` / `⌘0` — масштаб (запоминается для сайта)
- `⌘⇧C` — скопировать ссылку без меток отслеживания
- `⌘⇧M` — выключить или включить звук вкладки
- `⌘⇧R` — режим чтения
- `⌘D` — добавить в закладки, `⌘⇧B` — закладки, `⌘Y` — история
- `⌃1`…`⌃9` — профиль по номеру
- `⌘O` — открыть PDF, Markdown или HTML
- `⌃⌥S` — показать или скрыть панель вкладок
- `F12` (или `fn F12`) / `⌥⌘I` — открыть/закрыть Web Inspector текущей вкладки; «Проверить элемент» есть в контекстном меню
- `⌘`-клик по ссылке — открыть её в фоновой вкладке рядом с текущей (в группе)

Вкладки, которые открывает страница (ссылки в новой вкладке, `window.open`), собираются в группу вместе с ней. Это выключается в **Настройки → Вкладки**. Когда скрывать верхнюю панель вкладок — всегда, только в оконном режиме или никогда — выбирается в **Настройки → Вкладки**.

Для закреплённой вкладки `⌘W` возвращает исходный закреплённый URL; явная кнопка закрытия удаляет вкладку.

## Распространение

Исходный код удобно публиковать в GitHub-репозитории, а собранный `Aircraft-0.4-alpha.zip` прикладывать к GitHub Release с тегом `v0.4-alpha`.

Локальная сборка подписывается ad-hoc. Для распространения без предупреждений Gatekeeper потребуется сертификат Apple Developer ID, hardened runtime и notarization.
